# 自律奖励

用户每日可领取一次固定金额（默认 5 元）的自律奖励收入。通过主界面右下角可展开面板触发。

## 交互流程

1. 主界面右下角显示 ✕ 按钮（替换原 FAB）
2. 点击 ✕ → 逆时针旋转 90°，向左伸出白色圆角面板，内含"忍"和"+"两个按钮
3. 点击"忍" → 自动记一笔 INCOME / OTHER / note="奖励" / 金额=配置值 → Snackbar"已添加[撤回]" → 面板收回
4. 今日已领过后，"忍"变灰不可点（点击轻震反馈），午夜后自动恢复
5. 点"+" → 导航到记账页（同原 FAB 逻辑）
6. 点面板外区域 → 面板收回
7. 再次点 ✕ → 顺时针旋转 90°，面板收回
8. 长按"忍" → 弹出修改金额弹窗，修改后立即生效

## 约束

- 每天只能领一次，0:00 重置
- 撤回不恢复当日资格
- 金额默认 5 元，可配置（SharedPreferences）
- 动画 250ms（旋转 90° + fade/slide）
- AnimePink 主题配色
